# gh-contributor Skill

GitHub 贡献分析工具 — 帮助开发者追踪贡献进度、发现机会、进入 Top 50！

## 功能

- 分析任意仓库的贡献者排名
- 追踪个人贡献进度
- 发现 "good first issue" 机会
- 生成贡献报告

## 安装

```bash
clawhub install gh-contributor
```

## 使用

```bash
# 查看仓库贡献者排名
gh-contributor rank owner/repo

# 追踪自己的贡献进度
gh-contributor track owner/repo --user your-username

# 查找可贡献的 issues
gh-contributor issues owner/repo --label "good first issue"
```
